## How to use

Open `index.html`. Relative links keep the site portable. Browser local-storage behavior is most consistent when the folder is served from a local static HTTP server or published to normal web hosting.

Example local server (if Python is installed):

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/`.
