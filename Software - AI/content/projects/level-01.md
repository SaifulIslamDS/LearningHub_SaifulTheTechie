## The brief

Build a personal developer portfolio that works as a real static website, not only as a screenshot.

## What you will prove

| Skill | Evidence |
|---|---|
| Semantic HTML | Clear landmarks and heading hierarchy |
| CSS layout | Flexbox/Grid used deliberately |
| Responsive design | No horizontal scroll at 390 px; readable at 200% zoom |
| Accessibility | Labels, alt text, visible focus and keyboard reachability |
| Git/GitHub | Meaningful commits and a public repository |
| Deployment | Working public URL |

## Requirements

- [ ] Hero, About, Skills, Projects, Experience/Education, Contact and Footer.
- [ ] At least three project cards with problem, stack and evidence links.
- [ ] Responsive layout and navigation.
- [ ] Accessible contact-form UI.
- [ ] README with purpose, screenshots, run instructions and key decisions.
- [ ] Public deployment.

## Verification

Test at 390 px and wide desktop, zoom to 200%, navigate by keyboard, check all links, then have another person open the repository using only the README.

## Self-assessment

| Area | Meets the bar | Excellent |
|---|---|---|
| Structure | Semantic hierarchy | Deliberate landmarks/content model |
| Layout | Desktop + mobile | Fluid intermediate widths |
| Accessibility | Labels/focus/alt text | Keyboard and contrast review |
| Git | Several meaningful commits | History tells the build story |
| Evidence | Project links | Problem, decision and outcome explained |

**Done when:** it works offline, the repo is understandable, deployment works, and you can explain the decisions without relying on the tutorial.
