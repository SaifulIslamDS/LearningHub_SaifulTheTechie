This module turns **Authentication Advanced — Profile, Password & Email** into a guided Saiful The Techie learning sequence. Use the tutorials in order: understand the architecture first, then build the matching feature with the downloadable files.

## What you'll learn

- Module Intro: What we'll build — profile update, password
- Update Profile: Build profile update form and change
- Profile Image Upload: Upload image to server, save URL to database
- Change Password: Old password verify, new password set
- Forgot Password Flow: Request reset link, generate token, send email
- Reset Password Page: Validate token, set new password
- Email Verification: Send verification email on registration and verify
- Resend Verification Email: Handle resend logic and expiry
- Error Handling: Global error messages, edge cases
- Module Summary: Full auth system recap, best practices

## How to use this module

Read the tutorial while editing the practice project. Type the important code yourself, run what your local environment supports, and compare with the reference files only after you have attempted the step. Framework/cloud sections that could not be executed during release verification are labelled clearly instead of showing invented output.
