## Start here

This assignment is the first independence gate: build from written requirements rather than copying a finished page.

## Core idea

Requirements: semantic page structure, external CSS, navigation/hero, at least three sections, reusable cards, no horizontal scroll at 390 px, visible keyboard focus, meaningful Git commits, README and live deployment.

## Practice files and code trail

This tutorial is paired with `web-foundations-starter.zip`. Use the download as working material, not as a replacement for the explanation above. Open the starter/reference files, follow the code in order, run what can be run locally, and compare your result with the tutorial before moving on.

## Career build extension
## Assignment build brief

Create a one-page **Developer Portfolio** without copying the completed practice file. Use the source requirements as a checklist, then make your own content and design decisions.

Required sections:

```text
Header / navigation
Hero
About
Skills
Projects or resume/experience
Contact
Footer
```

Your CSS must demonstrate Flexbox or Grid, spacing with the box model, reusable classes and a responsive adjustment for smaller screens.

## Submission evidence

Submit both the repository and live page when possible. The README should include a screenshot, feature list, technology list and short note about what you learned. Before submitting, test every internal link, external link and form label.

The goal is not to reproduce an instructor screenshot pixel-for-pixel. The goal is to prove that you can take requirements and produce a clean, readable web page independently.
