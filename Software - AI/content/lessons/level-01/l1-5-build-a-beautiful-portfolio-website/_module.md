This module teaches **Build a beautiful portfolio website** as part of the beginner-to-career Software & AI Engineering path. The module topics are taught through connected explanations, examples and practice files.

## What you'll learn

- Module Introduction, project overview, and git setup
- Set Google fonts and set navbar and primary colour
- Banner content and portfolio image using flex
- Simple image background, and about section
- Use Flexbox for about info and start the What I am
- Technical skills, flex gap, and how to apply flex
- Resume section Education and Experience area
- Style contact form and GitHub page hosting, live link
- Module summary and Font Awesome

## How to use this module

Follow the tutorials in order and keep the practice package open beside the lesson. Type and modify the code yourself; use completed/reference files for comparison rather than copying them as a shortcut.
