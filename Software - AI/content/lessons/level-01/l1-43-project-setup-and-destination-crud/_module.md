This module turns **Project Setup & Destination CRUD** into a guided Saiful The Techie learning sequence. Use the tutorials in order: understand the architecture first, then build the matching feature with the downloadable files.

## What you'll learn

- Project Initialization & Dependencies Setup
- UI Library Integration (Hero UI) and Navbar & Footer
- Database Connection & Server Design
- Home Page Design & explore Swiper.js
- Feature: Add Destination Form and create Post API
- Feature: GET All Destinations & Display
- Feature: Destination Details Page
- Feature: Edit Destination
- Feature: Delete Destination
- Module Summary

## How to use this module

Read the tutorial while editing the practice project. Type the important code yourself, run what your local environment supports, and compare with the reference files only after you have attempted the step. Framework/cloud sections that could not be executed during release verification are labelled clearly instead of showing invented output.
