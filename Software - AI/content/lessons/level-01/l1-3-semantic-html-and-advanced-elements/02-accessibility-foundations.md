## Start here

Accessibility means people can perceive, understand and operate the interface across different abilities, devices and input methods.

<div class="admonition job"><p class="admonition-title">Why it matters at work</p><p>This bridge topic prevents common gaps that appear when tutorial code is moved into real projects.</p></div>

## Core idea

Prefer native buttons/links, meaningful headings, persistent form labels, useful alt text, visible keyboard focus and readable contrast.
