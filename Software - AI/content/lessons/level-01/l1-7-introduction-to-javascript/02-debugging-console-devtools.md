## Start here

Debugging is finding why actual behavior differs from expected behavior.

<div class="admonition job"><p class="admonition-title">Why it matters at work</p><p>This bridge topic prevents common gaps that appear when tutorial code is moved into real projects.</p></div>

## Core idea

Use a loop: reproduce → read the full error → inspect the smallest relevant value → form one hypothesis → change one thing → rerun.
