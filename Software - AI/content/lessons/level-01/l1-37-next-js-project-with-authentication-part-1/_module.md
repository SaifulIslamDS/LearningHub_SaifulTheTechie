This module turns **Next.js Project with Authentication—Part 1** into a guided Saiful The Techie learning sequence. Use the tutorials in order: understand the architecture first, then build the matching feature with the downloadable files.

## What you'll learn

- Project Overview, Setup & Header Design
- Font & Date-FNS Integration and not-found page
- Implement Marquee & Design Navbar
- Recap & Design Grid Layout, Fetch Categories
- Display Categories & Design Sidebar
- Load News Data & Filter News Based on Category
- Display News Card and handle loading
- Show all News data and show dynamic news
- Module Summary

## How to use this module

Read the tutorial while editing the practice project. Type the important code yourself, run what your local environment supports, and compare with the reference files only after you have attempted the step. Framework/cloud sections that could not be executed during release verification are labelled clearly instead of showing invented output.
