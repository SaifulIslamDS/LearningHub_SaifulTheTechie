This module turns **Deep Dive into MongoDB Operators and Queries** into a guided Saiful The Techie learning sequence. Use the tutorials in order: understand the architecture first, then build the matching feature with the downloadable files.

## What you'll learn

- Install and setup NoSQL Booster and know more about MongoDB methods
- Comparison Operators: $eq, $ne, $gt, $gte, $lt, $lte
- Logical Operators: $and, $or, $not, $nor
- Element & Type Operators: $exists, $type
- Array Query Operators: $in, $nin, $all, $size, $elemMatch
- Update Operators: $set, $inc, $push, $pull, $addToSet
- Projection & Sorting: Include/Exclude using projection, sort(), limit(), skip()
- Aggregation Pipeline: $match, $group, $project
- Advanced Aggregation Operators: $lookup, $unwind,
- Module Summary

## How to use this module

Read the tutorial while editing the practice project. Type the important code yourself, run what your local environment supports, and compare with the reference files only after you have attempted the step. Framework/cloud sections that could not be executed during release verification are labelled clearly instead of showing invented output.
