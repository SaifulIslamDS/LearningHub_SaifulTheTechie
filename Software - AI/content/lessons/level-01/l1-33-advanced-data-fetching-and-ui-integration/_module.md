This module turns **Advanced Data Fetching & UI Integration** into a guided Saiful The Techie learning sequence. Use the tutorials in order: understand the architecture first, then build the matching feature with the downloadable files.

## What you'll learn

- Data Fetching Recap: How data flows in Next.js App Router
- Server Components: Fetching real data directly in Server Components
- Caching Behavior: Understanding default cache and when it breaks
- Caching Behavior: Dynamic Fetching - Using cache: 'no- store' for always-fresh data
- ISR with Revalidate: Incremental Static Regeneration in real projects
- generateStaticParams: Optimizing dynamic routes at build
- Lazy loading with next/dynamic
- Hero UI Setup: Installing and configuring Hero UI in Next.js (theme + config)
- Hero UI with Data: Rendering fetched data using Hero UI Cards and Lists
- Module Summary: Recap, best practices, and practice

## How to use this module

Read the tutorial while editing the practice project. Type the important code yourself, run what your local environment supports, and compare with the reference files only after you have attempted the step. Framework/cloud sections that could not be executed during release verification are labelled clearly instead of showing invented output.
