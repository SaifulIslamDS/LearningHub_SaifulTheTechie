This module teaches **Simple React SPA with BPL-DREAM** as part of the beginner-to-career Software & AI Engineering path. The module topics are taught through connected explanations, examples and practice files.

## What you'll learn

- BPL Dream project setup and include Tailwind and daisiUI
- Create navbar and Create Fake Data for the players and load data
- Set Layout and make React responsive
- Building Player Card Component
- State Management & Toggle Functionality
- Player Selection & Validation System
- Selected Players Component & Remove Functionality
- React Toastify Integration and deploy to Surge/Netlify/Vercel

## How to use this module

Follow the tutorials in order and keep the practice package open beside the lesson. Type and modify the code yourself; use completed/reference files for comparison rather than copying them as a shortcut.
