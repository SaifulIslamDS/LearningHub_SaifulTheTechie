This module turns **REST API & CRUD Operations with Express and MongoDB** into a guided Saiful The Techie learning sequence. Use the tutorials in order: understand the architecture first, then build the matching feature with the downloadable files.

## What you'll learn

- Database Setup: Creating a MongoDB Atlas Account
- Connection Logic: Async/Await & Try-Catch Block
- Create Operation: Create client-side and set POST operation
- Recap POST method and know about insertOne
- Display user Data in Client side UI
- Delete user from UI and Database & explore ObjectId
- Read Operation: Loading Single Item by ID
- Update Operation: PUT vs PATCH & Updating Data
- Update data and display on UI
- (Optional) Running MongoDB Locally (No Internet)

## How to use this module

Read the tutorial while editing the practice project. Type the important code yourself, run what your local environment supports, and compare with the reference files only after you have attempted the step. Framework/cloud sections that could not be executed during release verification are labelled clearly instead of showing invented output.
