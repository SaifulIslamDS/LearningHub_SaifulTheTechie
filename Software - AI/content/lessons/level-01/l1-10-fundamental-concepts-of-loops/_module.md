This module teaches **Fundamental Concepts of Loops** as part of the beginner-to-career Software & AI Engineering path. The module topics are taught through connected explanations, examples and practice files.

## What you'll learn

- What is a Loop? Explore the for loop
- Introduction to While Loop
- Problem-solving with While Loop
- Introduction to For Loop
- Problem-solving with For Loop (Task)
- Different ways to use loop
- When to use a break and continue
- (optional) Introduction to Do While Loop
- Difference between types of loops Module Summary

## How to use this module

Follow the tutorials in order and keep the practice package open beside the lesson. Type and modify the code yourself; use completed/reference files for comparison rather than copying them as a shortcut.
