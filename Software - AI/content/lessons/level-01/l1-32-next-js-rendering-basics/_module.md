This module turns **Next.js Rendering Basics** into a guided Saiful The Techie learning sequence. Use the tutorials in order: understand the architecture first, then build the matching feature with the downloadable files.

## What you'll learn

- What is Rendering? What is CSR and SSR?
- About Hydration. CSR vs. SSR and Next Js Rendering Techniques
- Client Components vs. Server Components
- Loading Data Using Client Component
- Loading Data Using Server Component and Client Component inside Server Component
- Displaying All Foods, Food Details and Use of error.js and loading.js
- Module Summary

## How to use this module

Read the tutorial while editing the practice project. Type the important code yourself, run what your local environment supports, and compare with the reference files only after you have attempted the step. Framework/cloud sections that could not be executed during release verification are labelled clearly instead of showing invented output.
