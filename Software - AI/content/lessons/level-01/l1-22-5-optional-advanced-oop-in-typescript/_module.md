This module teaches **(Optional Advanced) OOP in TypeScript** as part of the beginner-to-career Software & AI Engineering path. The module topics are taught through connected explanations, examples and practice files.

## What you'll learn

- Introduction to OOP
- Understanding Classes & Object Modeling
- Constructors and Method Design
- Inheritance and Code Reusability
- Type Narrowing and Type Safety
- Access Modifiers and Data Protection
- Getters, Setters, and Static Members
- Polymorphism in Practice
- Abstraction for Scalable Design
- Encapsulation and Data Integrity
- Module Summary

## How to use this module

Follow the tutorials in order and keep the practice package open beside the lesson. Type and modify the code yourself; use completed/reference files for comparison rather than copying them as a shortcut.
