This module teaches **Fundamentals of Strings & Objects** as part of the beginner-to-career Software & AI Engineering path. The module topics are taught through connected explanations, examples and practice files.

## What you'll learn

- Introduction to string and string vs array
- String Comparison lowercase, uppercase and trip
- String Slice, Join, Concatenate and includes
- Reverse a String in Three Different Ways
- Introduction to Objects properties, and values
- What is Object Animated video
- Multiple ways to get & set object properties slide: [11-13]
- Keys, Values, nested objects and delete
- Loop an object and Ways to declare an Object
- Module Summary and Practice Tasks

## How to use this module

Follow the tutorials in order and keep the practice package open beside the lesson. Type and modify the code yourself; use completed/reference files for comparison rather than copying them as a shortcut.
