## Start here

Responsive design makes one interface adapt to different viewport sizes and user settings.

<div class="admonition job"><p class="admonition-title">Why it matters at work</p><p>This bridge topic prevents common gaps that appear when tutorial code is moved into real projects.</p></div>

## Core idea

Start with a simple narrow layout. Add wider layout only when content needs it. Use fluid sizes and `max-width`, and let content determine breakpoints.
