This module turns **Security & Authentication in Next.js with BetterAuth** into a guided Saiful The Techie learning sequence. Use the tutorials in order: understand the architecture first, then build the matching feature with the downloadable files.

## What you'll learn

- What you will learn from this Milestone-1 (Animated)
- BetterAuth Intro: Architecture overview and project setup
- MongoDB Adapter: Configure BetterAuth with MongoDB
- Auth Client & Register: Create auth client helper and registration page
- Login Page: Build login UI and handle credentials sign-in
- Session Management: Access session data in Components
- Route Protection: Protect routes with proxy
- Google OAuth: Config, credentials setup, and callback URLs
- GitHub OAuth: GitHub sign-in and save social users to the database
- Logout & Deploy: Complete logout system and deployment
- Module Summary: auth flow review, and practice task

## How to use this module

Read the tutorial while editing the practice project. Type the important code yourself, run what your local environment supports, and compare with the reference files only after you have attempted the step. Framework/cloud sections that could not be executed during release verification are labelled clearly instead of showing invented output.
