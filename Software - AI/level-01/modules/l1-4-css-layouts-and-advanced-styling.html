CSS Layouts & Advanced Styling

Learn the CSS layout systems that make modern interfaces work across screen sizes: units, Flexbox, Grid, responsive design, pseudo selectors and positioning.

1. Layout is constraint management

Good CSS layout is not about memorizing properties. It is about deciding how content should behave when space grows, shrinks or changes orientation.

2. CSS units: choose the right reference

UnitUseful forThink about
pxBorders, small fixed detailsAbsolute CSS pixel unit
%Relative sizingDepends on containing context
remTypography and spacing systemsRelative to root font size
emComponent-relative sizingRelative to current/inherited font size
vw/vhViewport-relative effectsUse carefully for readable interfaces

3. Flexbox fundamentals

CSS.nav { display: flex; align-items: center; justify-content: space-between; gap: 1rem; } .nav-links { display: flex; gap: .75rem; }

Main axis follows flex-direction. Cross axis is perpendicular. This mental model makes justify-content and align-items much easier.

4. CSS Grid fundamentals

CSS.cards { display: grid; grid-template-columns: repeat(3, minmax(0, 1fr)); gap: 1rem; }

Grid is excellent when rows and columns both matter. Flexbox is usually stronger for one-dimensional alignment.

5. ST Recommended: responsive design

ST RECOMMENDED

Start from a small-screen layout, then add complexity only when space allows.

CSS.cards { display: grid; grid-template-columns: 1fr; gap: 1rem; } @media (min-width: 48rem) { .cards { grid-template-columns: repeat(2, 1fr); } } @media (min-width: 72rem) { .cards { grid-template-columns: repeat(3, 1fr); } }

6. Pseudo-classes and pseudo-elements

CSSa:hover { text-decoration-thickness: 3px; } button:focus-visible { outline: 3px solid #5b37ff; outline-offset: 3px; } .card::before { content: ""; display: block; height: 4px; background: currentColor; }

Do not remove focus outlines unless you provide a clearly visible replacement.

7. Positioning and z-index

Use normal flow, Flexbox and Grid first. Use position when an element genuinely needs an offset or attachment behavior.

CSS.header { position: sticky; top: 0; z-index: 10; } .badge { position: absolute; inset: 1rem 1rem auto auto; } .card { position: relative; }

8. Build three layout patterns

  1. Navbar: logo + navigation + action.
  2. Hero: text and image side by side on wide screens, stacked on small screens.
  3. Card grid: one, two or three columns depending on space.

10. Debugging layout

  • Inspect the parent first: is it actually display:flex or grid?
  • Check fixed widths that prevent shrinking.
  • Use minmax(0, 1fr) where long content can overflow a grid track.
  • Temporarily add outlines to visualize boxes.
  • Test keyboard focus and zoom, not just screen width.

11. Knowledge check

When is Flexbox usually a better fit than Grid?

When you mainly care about one dimension or alignment along a single axis.

Why use rem for much of a spacing system?

It gives a consistent scale tied to the root font size.

What does :focus-visible help with?

Providing visible keyboard focus without forcing the same focus indicator for every pointer interaction.
