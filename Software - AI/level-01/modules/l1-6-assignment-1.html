1. Assignment brief

Build a responsive multi-section portfolio from a written specification. This is not a copy exercise. You may consult documentation and your previous lessons, but the implementation decisions should be yours.

Source note: the source curriculum specifies rules/requirements and submission guidance but does not provide detailed requirements in the uploaded syllabus. The rubric below is a Saiful the Techie tutorial expansion, not source-course grading criteria.

2. Required features

  • Semantic header, navigation, main and footer.
  • Hero section with clear call to action.
  • About, skills, project and contact sections.
  • At least one structured data section such as education/experience.
  • Responsive layout using Flexbox and/or Grid.
  • Accessible form labels and visible keyboard focus.
  • No horizontal overflow at common mobile widths.
  • Git repository with at least six meaningful commits.
  • README and live deployment.

3. Constraints

  • No CSS framework for this assignment.
  • No copying a complete template.
  • No secrets or private data in the repository.
  • Images must have useful alternative text where informative.
  • All navigation links must work.

4. Self-assessment rubric

AreaExcellentNeeds work
HTML structureSemantic, logical headings, clean formsDiv-heavy, skipped hierarchy, unlabeled inputs
CSSConsistent spacing, reusable classes, responsiveRepeated values, fixed layout, overflow
GitSmall meaningful commits and clear READMESingle commit or unclear history
AccessibilityKeyboard usable, focus visible, alt text/labelsMouse-only or missing labels
DeploymentLive URL works and assets loadBroken links or missing assets

5. Submission package

  1. GitHub repository URL.
  2. Live site URL.
  3. README with screenshots and learning summary.
  4. Short reflection: three decisions you made and one thing you would improve.

6. Pre-submission checklist

  • Open every page and click every link.
  • Test 320px–1440px widths with DevTools.
  • Navigate using only the keyboard.
  • Run through form labels and image alt text.
  • Open the site from the deployed URL—not only locally.
  • Check git status is clean after your final commit.

7. Independent challenge mode

CHALLENGE

Rebuild the portfolio from only the requirements and rubric—without re-reading the guided project steps. This tests whether the skill transferred.

8. What comes next

Once this assignment feels manageable, continue to JavaScript Foundations. The web-foundation pages remain available as a reference whenever you need to debug structure, layout or Git workflow.
