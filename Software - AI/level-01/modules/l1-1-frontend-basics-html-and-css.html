Frontend Basics: HTML & CSS

Build a correct first page, understand the browser-facing foundations, and practice HTML/CSS through a guided lab.

1. Lesson overview

HTML describes structure and meaning. CSS controls presentation. In this lesson you will build a small page from a blank folder, style it, inspect it in the browser, and practice the habits that later make React and Next.js easier.

2. Learning objectives

  • Create a valid HTML document and connect an external stylesheet.
  • Use headings, paragraphs, lists, links, images, buttons and form controls.
  • Choose tag, class and id selectors appropriately.
  • Reason about the CSS box model.
  • Use basic typography, backgrounds, display and positioning.
  • Diagnose common path and selector errors.

3. Mental model: structure → style → behavior

HTML

Structure and meaning.

CSS

Appearance and layout.

JavaScript

Behavior and logic, introduced later.

Professional habit: start with meaningful HTML before polishing the design.

4. Build your first page

Create index.html and style.css in the same folder.

index.html<!doctype html> <html lang="en"> <head> <meta charset="utf-8"> <meta name="viewport" content="width=device-width, initial-scale=1"> <title>My First Page</title> <link rel="stylesheet" href="style.css"> </head> <body> <main class="profile"> <h1>Saiful Islam</h1> <p>Learning software and AI engineering.</p> <a href="https://saifulshuvo.com">Visit my website</a> </main> </body> </html>
style.css* { box-sizing: border-box; } body { margin: 0; font-family: system-ui, sans-serif; background: #f4f5fb; } .profile { max-width: 640px; margin: 64px auto; padding: 32px; background: white; border-radius: 18px; }

5. Text, lists, links, images and buttons

Use headings to express hierarchy—not simply to make text larger. Use lists for collections, descriptive link text for navigation, and useful alternative text for informative images.

HTML<h2>Skills</h2> <ul> <li>HTML</li> <li>CSS</li> </ul> <img src="profile.jpg" alt="Saiful Islam working at a laptop"> <a class="button" href="projects.html">View projects</a>

6. Forms: build the user interface correctly

Labels and meaningful input names matter from the beginning. A form can look correct while still being difficult to use with a keyboard or screen reader.

HTML<form> <label for="name">Name</label> <input id="name" name="name" type="text" required> <label for="role">Role</label> <select id="role" name="role"> <option value="student">Student</option> <option value="developer">Developer</option> </select> <button type="submit">Send</button> </form>

7. CSS selectors and cascade basics

Element

p { color: #333; }

Class

.note { color: blue; }

ID

#hero { min-height: 50vh; }

Classes are usually the most reusable choice for visual styling. When rules conflict, specificity and source order help determine which declaration wins.

8. Box model

Inside → outside: content → padding → border → margin.
CSS.card { width: 320px; padding: 24px; border: 1px solid #d9ddeb; margin: 24px auto; }

With box-sizing: border-box, declared width includes padding and border, which is easier to reason about in most layouts.

9. Display, visibility and basic position

display: none removes an element from layout. visibility: hidden hides it while keeping its space. Positioning is powerful, but avoid using absolute positioning to solve ordinary page layout.

10. Debug with browser DevTools

  1. Right-click an element and choose Inspect.
  2. Turn CSS declarations on and off.
  3. Inspect the box model panel.
  4. Use the responsive-device toolbar to test narrow screens.

13. Common mistakes

CSS not loading

Verify filename, extension and relative path.

Selector does nothing

Check . for class and # for id, then inspect specificity.

Image missing

Check case-sensitive path and file extension.

Layout unexpectedly large

Inspect width, padding, border and margin together.

14. AI-assisted workflow

Useful prompt: “Review this HTML/CSS. Identify one structural problem, one accessibility problem and one CSS problem. Explain them before giving fixes.”
Do not outsource the exercise: attempt it first, then use AI to review or debug your work.

15. ST Recommended: accessibility from day one

ST RECOMMENDED

Use meaningful headings, labels, alt text, descriptive links, visible keyboard focus and readable contrast. Accessibility is easier when built in early than retrofitted later.

Accessibility foundations →

16. Knowledge check

What is HTML mainly responsible for?

Structure and meaning of page content.

What are the four box-model layers?

Content, padding, border and margin.

Why is a label useful in a form?

It gives the control an accessible name and improves interaction.

When is a class usually better than an id for CSS?

When the style should be reusable across multiple elements.
