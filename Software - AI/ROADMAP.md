### v0.6 quality direction

- Continue the deep tutorial model established in v0.5.
- Prefer multiple learner-friendly tutorials where a source module is too broad for one coherent chapter.
- Use executable Node/TypeScript/PostgreSQL examples where tooling exists.
- Build a realistic PostgreSQL-backed API rather than isolated snippets only.
- Teach relational modelling, normalization, keys, joins, indexing and `EXPLAIN` as connected engineering decisions.
- Keep optional YouTube companions selective and subordinate to the written tutorial.
- Expand practice packages so code shown in tutorials remains synchronized with starter/completed material.
