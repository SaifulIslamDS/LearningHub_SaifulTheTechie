HTML Cheat Sheet

Compact reference for Web Foundations. Use the full tutorials when you need explanation.

Document

<!doctype html> <html lang="en"> <head>...</head> <body>...</body> </html>

Structure

header · nav · main · section · article · aside · footer

Text & links

h1–h6 · p · ul/ol/li · a · strong · em

Forms

form · label · input · select · option · textarea · fieldset · legend · button

Accessibility reminders

  • One clear page heading.
  • Logical heading hierarchy.
  • Labels for controls.
  • Useful alt text for informative images.
  • Descriptive link text.
