Lab 06 — Debug a Broken Web Page

Practice a repeatable debugging workflow on deliberate HTML, path, layout and accessibility defects.

Broken starter

<link rel="stylesheet" href="styles.css"> <div class="navbar"> <div onclick="location.href='index.html'">Home</div> </div> <img src="Images/profile.PNG"> <div class="cards">...</div>
.cards { display:grid; grid-template-columns:repeat(3, 400px); gap:24px; } @media (max-width:600px){ .card { width:380px; } }

Your job

  1. Find why the stylesheet may not load if the actual file is css/style.css.
  2. Replace the clickable div with semantic navigation.
  3. Fix image path/casing and add alt text.
  4. Make the card layout fluid without horizontal scrolling.
  5. Add keyboard focus styles.

Debugging log

For each issue, write: symptom → hypothesis → inspection → fix → verification. This habit matters more than guessing quickly.

Lab status
Mark complete when you have a working result and completed the checks.

Lab rule

Type the code yourself. If you get stuck, debug first; then consult the lesson or documentation.
