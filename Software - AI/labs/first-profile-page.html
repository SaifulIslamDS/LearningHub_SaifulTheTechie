HANDS-ON LAB

Lab 01 — First Profile Page

Build a one-page personal profile using semantic HTML, an external stylesheet and a small responsive card layout.

Outcome

A profile page with name, bio, skills, useful links and a contact section.

Starter structure

profile-page/ index.html style.css images/ profile.jpg

Tasks

Structure

Create header, main and footer. Put the profile content inside meaningful sections.

Content

Add one h1, a short bio, a skills list and two meaningful links.

Style

Use an external stylesheet, max-width container, spacing scale and a card-like surface.

Responsive check

At narrow widths, the page must fit without horizontal scrolling.

Checkpoints

  • Every image has appropriate alt text.
  • CSS is loaded externally.
  • No text is centered merely because it looks “modern.”
  • Links describe their destination.
  • The page works with browser zoom.

Stretch

Add a project card, then style it using the same spacing and border system as your profile card.

Lab status
Mark complete when you have a working result and completed the checks.

Lab rule

Type the code yourself. If you get stuck, debug first; then consult the lesson or documentation.
