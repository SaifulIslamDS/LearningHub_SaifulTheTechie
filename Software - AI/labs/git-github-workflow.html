HANDS-ON LAB

Lab 05 — Git & GitHub Workflow

Take a small web project from an untracked folder to a GitHub repository with clean commits, a feature branch and a pull request.

Scenario

You have an existing profile page that is not version controlled.

Tasks

Initialize

git init git status

First commit

git add . git commit -m "Add initial profile page"

Remote

Create a GitHub repository, add origin, and push main.

Feature branch

git switch -c feature/contact-section

Add a contact section and commit it.

Pull request

Push the branch and open a pull request. Review the diff before merging.

Evidence

  • At least three meaningful commits.
  • One feature branch.
  • One pull request merged.
  • README includes live purpose and file structure.
Lab status
Mark complete when you have a working result and completed the checks.

Lab rule

Type the code yourself. If you get stuck, debug first; then consult the lesson or documentation.
