Lab 03 — Flexbox Navbar + Hero

Build a responsive navigation bar and two-column hero using Flexbox, then stack it for small screens.

Goal

Build a header with brand, navigation and CTA plus a hero with text and image.

Base CSS

.nav { display:flex; align-items:center; justify-content:space-between; gap:1rem; } .nav-links { display:flex; gap:.75rem; flex-wrap:wrap; } .hero { display:flex; align-items:center; gap:2rem; } .hero > * { flex:1; } @media (max-width: 48rem) { .hero { flex-direction:column; align-items:stretch; } }

Experiment

  1. Change justify-content on the nav.
  2. Remove flex: 1 from the hero children and observe.
  3. Increase the image width and fix overflow without a hardcoded mobile width.

Quality checks

  • Nav can wrap without overlapping.
  • Hero stacks on small screens.
  • Image uses max-width:100%.
  • CTA has a visible focus state.
Lab status
Mark complete when you have a working result and completed the checks.

Lab rule

Type the code yourself. If you get stuck, debug first; then consult the lesson or documentation.
