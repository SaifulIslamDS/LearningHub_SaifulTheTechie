HANDS-ON LAB

Lab 02 — Accessible Registration Form

Create a registration form with labels, grouped choices, validation hints and keyboard-friendly interaction.

Brief

Build a form for name, email, role, experience level, interests, password and a short goal statement.

Required HTML

  • label connected to every form control.
  • fieldset + legend for related radio/checkbox choices.
  • textarea for the goal statement.
  • Useful type values such as email and password.

Starter

<form> <label for="email">Email</label> <input id="email" name="email" type="email" required> <fieldset> <legend>Experience level</legend> <label><input type="radio" name="level" value="beginner"> Beginner</label> <label><input type="radio" name="level" value="intermediate"> Intermediate</label> </fieldset> </form>

Checks

  • Clicking a label activates its input.
  • You can reach every control with the keyboard.
  • Focus is visible.
  • Error-prone fields include clear instructions.
Lab status
Mark complete when you have a working result and completed the checks.

Lab rule

Type the code yourself. If you get stuck, debug first; then consult the lesson or documentation.
