Accessibility Foundations

A practical starter checklist for building interfaces that remain usable beyond mouse-only, perfect-vision scenarios.

1. Start with semantic HTML

Native HTML controls already carry behavior and semantics. Prefer a real button to a clickable div.

2. Keyboard first

Use Tab, Shift + Tab, Enter and Space to test interaction. Keep a visible focus indicator.

3. Give controls accessible names

<label for="email">Email address</label> <input id="email" name="email" type="email">

Placeholder text is not a substitute for a label.

4. Alternative text

Describe the purpose or information of an informative image. Use empty alt text for a truly decorative image: alt="".

5. Color and contrast

Do not communicate status by color alone. Ensure text and important UI affordances remain distinguishable.
