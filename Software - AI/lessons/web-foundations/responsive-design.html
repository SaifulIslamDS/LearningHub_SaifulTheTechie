ST RECOMMENDED

Responsive Web Design

An ST Recommended bridge from fixed layouts to interfaces that adapt to real devices, zoom levels and content lengths.

1. Start with content, not breakpoints

A responsive page should remain readable as available space changes. Avoid designing one desktop screenshot and then trying to squeeze it into a phone.

2. Mobile-first CSS

.hero { display: grid; gap: 2rem; } @media (min-width: 48rem) { .hero { grid-template-columns: 1.2fr .8fr; align-items: center; } }

3. Prefer fluid constraints

img { max-width: 100%; height: auto; } .container { width: min(100% - 2rem, 72rem); margin-inline: auto; } h1 { font-size: clamp(2rem, 5vw, 4.5rem); }

4. Test behavior

  • Resize slowly, not only at named device presets.
  • Zoom to 200% and check reflow.
  • Use long text to expose brittle cards.
  • Check portrait and landscape.
