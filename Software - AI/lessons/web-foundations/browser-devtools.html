Browser DevTools for HTML & CSS

A debugging-first mini-tutorial for inspecting markup, CSS rules, the box model and responsive behavior.

1. Inspect the real element

Right-click the visible element and choose Inspect. Work from the browser's actual DOM and applied styles rather than guessing.

2. Toggle CSS live

Enable/disable declarations, edit values and watch the result immediately. Changes in DevTools are temporary until copied back to your source files.

3. Read the box model

The computed/layout panel reveals content size, padding, borders and margins. This is usually faster than staring at the stylesheet.

4. Responsive mode

Use the device toolbar to test narrow widths. Do not trust only one preset—drag the viewport across widths and look for the exact point the layout breaks.

5. Debugging workflow

  1. Reproduce the issue.
  2. Inspect the element and its parent.
  3. Check applied and overridden styles.
  4. Change one thing at a time.
  5. Copy the proven fix into source.
  6. Reload and verify.
