# React/Vite starter reference — Saiful The Techie

This folder is intentionally source-only. The v0.4 build environment could not download npm packages, so the package was not installed or built here.

## Use it

1. Scaffold a current Vite React project: `npm create vite@latest`
2. Choose **React** and JavaScript (or TypeScript if you prefer).
3. Copy this folder's `src/` files into the new project.
4. Run `npm install` then `npm run dev`.
5. Compare your environment with the official React and Vite docs linked in the tutorials.

Reviewed 2026-10-09. React official docs reported 19.3; Vite site reported 8.3.x during review. Always check the official docs before pinning production dependencies.
