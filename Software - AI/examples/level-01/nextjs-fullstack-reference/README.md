# Next.js + Authentication reference files

These files mirror the tutorial code for Level 01 Modules 31–39.

## How to use

Create a fresh Next.js App Router project using the official `create-next-app` workflow. Copy these files into that project gradually as the tutorials introduce them. Do not paste the whole package at once: the learning value comes from building the route tree yourself.

The release builder did not install Next.js or Better Auth packages, so framework-specific files are **reference-only** in this package. Pure data examples in `lib/` can be inspected without external services.
