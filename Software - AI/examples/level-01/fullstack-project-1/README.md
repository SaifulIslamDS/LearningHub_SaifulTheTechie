# Full-Stack Project 1 Blueprint

Use this blueprint with Level 01 Modules 47–52. It intentionally contains planning and architecture artefacts rather than a finished application. Your task is to turn the specification into a working portfolio project.

Suggested product: **SkillBridge** — users discover learning services, purchase a package, and access a role-based dashboard.

Build order: PRD → wireframe → database model → API contracts → auth/RBAC → CRUD → Stripe test flow → deployment checklist.
