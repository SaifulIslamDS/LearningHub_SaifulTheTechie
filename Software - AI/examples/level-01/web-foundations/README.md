# Web Foundations practice package

1. Open `starter/index.html` and `starter/style.css`.
2. Follow the **HTML & CSS Foundations** tutorial in the Learning Hub.
3. Build each section yourself before comparing with `completed/`.
4. Use `completed/` only after you have tried the steps.

The tutorial and this package are designed as one learning path: the code snippets in the lesson map directly to these files.
