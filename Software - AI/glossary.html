Engineering glossary

A growing plain-language glossary. Milestone 0 establishes the structure; later milestones expand terms alongside tutorials.

API

Application Programming Interface — a defined way for software systems or components to communicate.

RAG

Retrieval-Augmented Generation — a pattern where relevant external information is retrieved and supplied to a model before it generates a response.

RBAC

Role-Based Access Control — authorization based on roles such as admin, moderator or user.

SSR

Server-Side Rendering — producing page HTML on the server before sending it to the browser.
