# Data, AI & Automation Path — Phase 3 scripts (Data Engineering)

Every script prints the same results you see in the lessons. The `data/` folder holds the 2025 practice data from Phase 2 plus small deterministic Phase 3B practice inputs such as the CDC event log.

## Set up once

```bash
uv init --bare
uv add requests beautifulsoup4 pandas pyarrow "psycopg[binary]" duckdb sqlglot deltalake "pyiceberg[sql-sqlite,pyarrow]" pytest jsonschema "great_expectations==1.24.0"
```

PostgreSQL (for scripts 03–10), easiest with Docker:

```bash
docker run --name pg -e POSTGRES_PASSWORD=practice -p 5432:5432 -d postgres:18
export DATABASE_URL=postgresql://postgres:practice@localhost:5432/postgres     # Windows PowerShell: $env:DATABASE_URL="..."
uv run 03_load_postgres.py
psql "$DATABASE_URL" -f 04_ctes.sql          # or paste the SQL into any client (DBeaver, pgAdmin, VS Code)
```

| `06_normalization.sql`, `07_indexing_explain.sql`, `08_transactions.py` | Database engineering |
| `09_star_schema.sql`, `10_scd.sql`, `11_bigquery_sql.py` | Data warehousing |

| `14_modular_incremental_pipeline.py` | ETL / ELT · modular pipelines, idempotency and incremental loads |
| `15_cdc_replay.py` | ETL / ELT · replayability and change data capture |
| `16_data_quality_validation.py`, `test_16_data_quality_validation.py` | Data quality · validation rules and pytest |

| `18_data_contract_freshness.py`, `contracts/orders_contract.schema.json` | Data quality · data contracts, freshness and alerting |
| `19_dbt_logic_verification.py` | dbt · RUN-HERE verification of the transformation business logic and known answers |

| `dbt_orders_project/` | dbt · synchronized `starter/` and `completed/` project (dbt Core v1.12 + dbt-duckdb) |
| `docker/` | Docker: `Dockerfile`, `Dockerfile.api`, `compose.yaml`, `ingest_job.py` |

Generated folders (`landing/`, `formats/`, `lake/`, `iceberg_warehouse/`, `results/`, `docker/output/`) can be deleted at any time. The dbt project writes its local database to `dbt_orders_project/completed/data/phase3.duckdb`, which is also disposable and ignored.

`data/orders_cdc_events.jsonl` is generated by `tools/make_phase3b_etl_data.py` with fixed seed 2026. The generator also copies the file to `content/downloads/phase-3/` for the lesson download.
