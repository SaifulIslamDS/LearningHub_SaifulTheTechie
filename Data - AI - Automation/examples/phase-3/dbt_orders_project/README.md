# Saiful The Techie — Phase 3 dbt Orders Project

Use **starter/** while following the three dbt tutorials. Use **completed/** to compare your work or run the reference implementation.

Both versions contain deterministic copies of the 2025 Phase 3 practice data. The completed project targets local DuckDB through `dbt-duckdb`, so no cloud warehouse is required.

## Recommended flow

1. Open `starter/`.
2. Follow **dbt Models and Tests**.
3. Continue with **Snapshots and Macros**.
4. Finish with **Documentation and Marts**.
5. Compare with `completed/`.
6. Run the reconciliation checks.

See each tutorial in the Saiful The Techie Data, AI & Automation Path for the explanation and verified outputs.
