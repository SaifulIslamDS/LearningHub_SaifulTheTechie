# Linux practice folder

Unzip this folder into your home directory as `~/practice` (on Windows, use WSL — see the Linux lessons).

```text
practice/
├── data/            orders.csv, orders_raw.csv, monthly/ (3 files)
├── logs/            cleaner-2026-03.log  (10 days of cleaner runs)
├── reports/         empty — your outputs go here
└── scripts/         daily_clean.sh (used in the cron lesson)
```
