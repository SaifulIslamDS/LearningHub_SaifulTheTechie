Phase 0 — Engineering Foundations

Build the technical base used by every later phase.
0
  • Development EnvironmentUpdated — VS Code, Python, uv / virtual environments, package management, debugging.
  • Git & GitHub — repositories, commits, branches, merge, pull requests, README, project structure.
  • Linux Essentials — filesystem, grep, sort, pipes, terminal workflow, cron concepts.
  • Programming Refresher — variables, conditions, loops, functions, collections, files, exceptions, OOP, type hints.
  • Testing & CI BasicsNew — pytest, linting (ruff), GitHub Actions to run tests on every push.
  • AI-Assisted DevelopmentNew — coding agents and copilots, prompting for code, reviewing and testing AI-written code.
Gate: A CSV Data Cleaning CLI with logging, exception handling, config, tests, CI and documentation.

Phase 1 — Data Analytics & Business Intelligence

Turn raw business data into decisions and executive reporting.
1
  • Excel for Analysis — IF, FILTER, SUMIFS, COUNTIFS, XLOOKUP, INDEX/MATCH, LET, conditional formatting.
  • Pivot Analysis — PivotTables, slicers, grouping, What-If Analysis, Goal Seek.
  • Power Query — cleaning, merge, append, reshape, multiple-file workflows.
  • Power Pivot & DAX — relationships, measures, CALCULATE, KPI logic, filter context.
  • Analytical SQL — SELECT, WHERE, GROUP BY, CASE, JOIN, subqueries and aggregation.
  • Power BIUpdated — data modeling, KPIs, drill-through, bookmarks, row-level security, service publishing, Copilot in Power BI.
  • Semantic Models & Metrics LayerNew — one trusted KPI definition reused across reports and AI tools.
  • AI-Assisted Analytics — AI for formulas, DAX, SQL and analysis, with human validation.
  • Data StorytellingNew — executive summaries, stakeholder communication, decision memos.
Milestone: Executive BI System using Excel/SQL/Power BI with KPI dictionary, semantic model and documented findings.
Optional cert: Microsoft PL-300 (Power BI Data Analyst).

Phase 2 — Python, Statistics & Data Science

Move from BI reporting into analytical programming and model thinking.
2
  • NumPy — arrays, vectorized operations, indexing, numerical computation.
  • Pandas — DataFrame operations, cleaning, merge, groupby, pivot and datetime.
  • Polars & DuckDBNew — fast DataFrames and in-process SQL for larger local data.
  • EDA — patterns, distributions, relationships, anomalies and analytical questions.
  • Statistics — central tendency, variance, distributions, correlation, confidence intervals.
  • Experimentation & A/B TestingNew — hypothesis tests, sample size, significance, causal pitfalls.
  • Visualization — Matplotlib, Seaborn, Plotly and analytical storytelling.
  • ML FoundationsUpdated — scikit-learn, train/test, leakage, scaling, feature engineering, bias/variance.
  • Research Thinking — research question, experiment design, reproducibility, evaluation and reporting.
Milestone: A documented business analytics study with EDA, statistics, an A/B or causal question, visuals and recommendations.

Phase 3 — Data Engineering (AI-ready)

Build the production data backbone for analytics and AI systems.
3
  • Data Ingestion — REST APIs, auth, pagination, scraping, CSV, JSON and Parquet.
  • Advanced SQL — CTEs, recursive CTEs, window functions, RANK, LAG, LEAD.
  • Database Engineering — PostgreSQL, normalization, indexing, transactions, EXPLAIN ANALYZE.
  • Data Warehousing — OLTP/OLAP, facts, dimensions, star schema, SCD, BigQuery.
  • Lakehouse & Open Table FormatsNew — Delta Lake / Apache Iceberg, Medallion layers, Microsoft Fabric or Databricks or Snowflake (pick one).
  • ETL / ELT — modular pipelines, idempotency, replayability, incremental loads, CDC.
  • Data Quality & ContractsUpdated — validation, pytest, Great Expectations, data contracts, freshness and alerting.
  • Docker — images, containers, compose and reproducible environments.
  • OrchestrationUpdated — Airflow (DAGs, retries, backfills); know Dagster/Prefect as alternatives.
  • dbt — models, tests, snapshots, macros, documentation and marts.
  • Cloud & Infrastructure as CodeUpdated — IAM, S3/GCS, BigQuery, Terraform basics, cost control.
  • AI-Ready DataNew — unstructured document pipelines, parsing, chunking, embedding refresh, metadata and lineage for RAG.
  • Big Data & Streaming — PySpark, partitions, shuffle, caching, Kafka producers/consumers.
Milestone: Production Analytics Platform with ingestion, orchestration, data quality, lakehouse/warehouse, BI layer and a document pipeline feeding a vector store.
Optional cert: Microsoft DP-700 (Fabric Data Engineer) or DP-600 (Fabric Analytics Engineer), or a cloud data-engineer cert.

Phase 4 — Machine Learning & Deep Learning Engineering

Move from analysis into deployable predictive systems.
4
  • Regression — linear regression, Ridge, Lasso, MAE, RMSE, R².
  • Classification — logistic regression, trees, gradient boosting (XGBoost/LightGBM), precision, recall, F1, ROC-AUC.
  • Unsupervised ML — K-Means, PCA, hierarchical clustering, DBSCAN, anomaly detection.
  • Time-Series ForecastingNew — trend, seasonality, backtesting, demand and sales forecasts.
  • Neural NetworksUpdated — forward pass, loss, backpropagation, with PyTorch as the main framework (Keras optional).
  • Computer Vision — CNNs, convolution, pooling, preprocessing and augmentation.
  • Applied CV — YOLO, fine-tuning, Roboflow, tracking, ONNX and TensorRT concepts.
  • MLOpsUpdated — FastAPI, Pydantic, Docker, MLflow registry, CI/CD for models, drift monitoring.
Milestone: Production ML API with /predict, /health and /info, containerized, deployed, versioned in MLflow and monitored.

Phase 5 — NLP, LLM & RAG Engineering

Build grounded language systems that use tools, context and private knowledge.
5
  • NLP Foundations — preprocessing, TF-IDF, embeddings (Word2Vec/GloVe as history).
  • Transformers — attention, encoder/decoder, BERT, T5, GPT and Hugging Face.
  • LLM Application EngineeringUpdated — APIs, structured outputs (JSON schema), function calling, streaming, cost awareness.
  • Prompt & Context Engineering — instructions, examples, constraints, context windows, retrieved context and state.
  • Open & Small ModelsNew — running SLMs locally (Ollama), when to choose open vs hosted models.
  • Fine-Tuning BasicsNew — LoRA/QLoRA, when fine-tuning beats prompting or RAG.
  • FrameworksUpdated — LangChain and LlamaIndex: chains, retrievers, tools.
  • Vector Databases — embeddings, similarity, chunking, FAISS, Chroma, Qdrant, Supabase/pgvector.
  • Advanced RAGUpdated — hybrid search, reranking, document parsing (PDF/tables), citations, GraphRAG concepts.
  • RAG EvaluationNew — golden datasets, retrieval recall, faithfulness, LLM-as-judge with human spot checks.
Milestone: Enterprise Knowledge Assistant with hybrid retrieval, citations, fallback handling, an eval dataset and traces.

Phase 6 — AI Agents & Intelligent Automation

Combine LLM reasoning with tools, memory, workflows and real business actions.
6
  • Agent Architecture — model, instructions, tools, memory, retrieval, control loop, guardrails.
  • Workflow vs Agent DesignNew — when a deterministic workflow beats an agent; agent skills as reusable procedures.
  • APIs, Webhooks & JSON for Agents — OAuth, bearer tokens, signatures, payloads, retries, rate limits.
  • n8n Advanced — branching, expressions, Code node, subflows, error handling, approval and logging.
  • Make.com & Zapier — scenario automation, SaaS connectivity and platform selection.
  • Code-First Agent FrameworksNew — LangGraph (state graphs), plus one vendor SDK (OpenAI Agents SDK or Claude Agent SDK).
  • MCP & A2AUpdated — build and consume MCP servers; agent-to-agent protocol concepts.
  • Human-in-the-Loop — approvals, escalation, confidence thresholds and fallback.
  • Agent Memory & State — conversation history, durable memory, state stores and retrieved knowledge.
  • Langflow — visual agent design, RAG flows and orchestration.
  • Multi-Agent Systems — CrewAI, AutoGen, supervisor patterns and agent collaboration.
  • Voice AI — STT, TTS, telephony, call flow, backend tools and human handoff.
  • Browser & Computer-Use AgentsUpdated — Playwright, navigation, extraction, agentic browser workflows.
Milestone: AI Operations Agent that retrieves information, performs approved actions, updates systems, escalates to humans and logs every step.

Phase 7 — Production AI, LLMOps & Governance

Make systems secure, observable, reliable, compliant and deployable.
7
  • Deployment — Docker, Render, AWS EC2, domains, HTTPS and environment management.
  • Reliability — retries, timeouts, queues, idempotency and graceful failure.
  • SecurityUpdated — secrets, least privilege, prompt-injection defense, tool permissions, sandboxing, OWASP LLM Top 10.
  • LLM ObservabilityNew — traces, spans and sessions with Langfuse or LangSmith; OpenTelemetry basics.
  • Evaluation & Regression TestingUpdated — offline evals before release, online evals in production, tool success, latency, cost.
  • Model Routing & GatewaysNew — LiteLLM-style gateways, fallbacks, caching, cheap-model-first routing.
  • AI FinOpsNew — token budgets, cost per task, usage dashboards.
  • AI Governance & Responsible AINew — EU AI Act risk tiers, NIST AI RMF, data privacy, bias checks, audit logs.
Gate: Deploy one robust AI system publicly with traces, eval suite, health checks, cost dashboard and security controls.

Phase 8 — Integrated Capstone

Combine all major capabilities into one end-to-end platform.
8
  • Data Layer — Excel/CSV, APIs, PostgreSQL and documents.
  • Engineering Layer — ingestion, Airflow, dbt, lakehouse/warehouse and quality controls.
  • Analytics Layer — SQL, semantic model and Power BI executive dashboard.
  • ML Layer — forecasting, classification or anomaly-detection model.
  • Knowledge Layer — embeddings, vector database and evaluated RAG.
  • Agent Layer — tools, memory, retrieval, approval and action execution.
  • Automation Layer — n8n, messaging, CRM, notifications and scheduled workflows.
  • Production LayerUpdated — cloud deployment, observability, evals, cost tracking, README and architecture diagram.
Capstone: Intelligent Business Operations Platform integrating Data + BI + ML + RAG + Agents + Automation + LLMOps.

Phase 9 — Career, Portfolio & Commercialization

Turn technical ability into evidence, opportunities and products.
9
  • GitHub Portfolio — polished repositories, architecture diagrams, demos and READMEs.
  • LinkedIn Positioning — expertise narrative, project-based credibility and visibility.
  • CV & Job SearchUpdated — role-targeted CV with measurable outcomes, ATS keywords, remote-job applications.
  • Interview PreparationNew — SQL/Python live coding, data-system design, AI-system design (RAG/agent architecture), take-home projects.
  • Certification StrategyNew — one cert per track only where it helps screening (e.g. PL-300, DP-700, a cloud AI cert).
  • Freelancing — profile positioning, proposals, scoping, pricing and client handover.
  • Case Studies — problem, solution, implementation, outcomes, limitations and lessons learned.
  • Productization — templates, packaged services, SaaS ideas and commercial solutions.
  • Ilmento Digital — convert mature capabilities into service or product opportunities.
Milestone: A job-ready and client-ready portfolio with clear proof of capability across the full stack.

Control Rules

These rules keep the curriculum accelerated, practical and non-repetitive.

Advance by competence

Move forward because the milestone works, not because time passed.

Skip intelligently

Rapidly review what you know. Spend depth on weak or high-value areas.

Build evidence

Every phase leaves code, dashboards, deployments, diagrams or documented outcomes.

Measure, don't guess

Every AI component ships with an eval set and traces before it counts as done.
