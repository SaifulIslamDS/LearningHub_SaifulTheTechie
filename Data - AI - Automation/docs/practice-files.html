Practice files

Every dataset, workbook, script, template and answer key used in the lessons. All files use the same small sales data, so results match across SQL, Excel, Power BI and Python.

Download everything at once
  • practice-files.zipAll 32 practice files in one zip · 766 KB

How to use them

Save the files in one folder (for example C:\Practice\ or ~/practice/). Lessons tell you which file to open. Files called solutions contain worked answers: try the exercise first. Each lesson also has its own download box at the top.
