Testing & CI BasicsNew

Build the technical base used by every later phase.

Professional code is checked automatically: tests prove it works, a linter keeps it clean, and continuous integration (CI) runs both on every change. That is how teams merge code with confidence, and how you show employers that your portfolio code is reliable.

Practice files

  • python-refresher.zip: the testing/ folder has sales.py, test_sales.py and a deliberately messy file for ruff.
  • csv-cleaner-solution.zip: a complete project with 17 tests and a working CI workflow.

By the end of this module you can: write and run pytest tests (including parametrized tests and temporary files), lint and format with ruff, and set up a GitHub Actions workflow that runs both on every push.
