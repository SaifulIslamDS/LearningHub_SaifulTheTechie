Git & GitHub

Part of Phase 0 — Engineering Foundations. Topics: Repositories & commits, Branches & merge, Pull requests, README & project structure.

Git records every change to your project, so you can experiment safely and go back in time. GitHub hosts your repositories online, so you can collaborate through pull requests and show your work to employers. Every data and AI job uses them, and your portfolio lives on GitHub.

Setup

  • Install Git: https://git-scm.com/downloads (Windows), brew install git (Mac), or sudo apt install git (Ubuntu/WSL).
  • Create a free account at https://github.com.
  • Tell Git who you are (once per computer):

bash git config --global user.name "Your Name" git config --global user.email "you@example.com" git config --global init.defaultBranch main

By the end of this module you can: save work in commits, work on branches, resolve a merge conflict, open a pull request, and present a repository with a clear README and structure.
