Programming Refresher

Part of Phase 0 — Engineering Foundations. Topics: Variables & conditions, Loops & functions, Collections, Files & exceptions, OOP, Type hints.

A fast, practical refresher of the Python you'll use every day as a data or AI engineer. Every example uses the same 12 sales orders as Phase 1, so you can compare Python's answers with SQL, Excel and Power BI.

Practice files

Download python-refresher.zip. It contains one script per lesson, the data file, a debugging exercise, testing examples and solutions to every exercise. Run a script with python 01_basics.py, or uv run 01_basics.py.

By the end of this module you can: write functions with conditions and loops, choose the right collection (list, dict, set, tuple), read and write CSV/JSON files safely, handle errors, and model data with classes and type hints.
