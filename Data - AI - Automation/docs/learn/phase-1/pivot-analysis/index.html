Pivot Analysis

Part of Phase 1 — Data Analytics & Business Intelligence. Topics: PivotTables, Slicers, Grouping, What-If Analysis, Goal Seek.

PivotTables summarise thousands of rows in seconds, without writing a single formula. In this module you build interactive summaries, filter them with clickable slicers, and test "what if" business scenarios.

Set up

  1. Open the practice workbook orders.xlsx and go to the Orders sheet.
  2. Click any cell in the data and press Ctrl + T (Mac: Cmd + T) to turn it into an Excel Table. Tick "My table has headers". A Table grows automatically when you add rows, and PivotTables built on it pick up the new data when you refresh them.

By the end of this module you can: build and reshape PivotTables, group dates and numbers, add slicers and timelines for self-service filtering, and answer planning questions with Data Tables and Goal Seek.
