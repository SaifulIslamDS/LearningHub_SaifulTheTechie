Excel for Analysis

Turn raw business data into decisions and executive reporting.

Excel is still the first analysis tool in almost every company. In this module you work with the same 12 orders as the SQL lessons. That way you can compare both tools and see that they give the same answers.

Set up once, practise every lesson

  1. Download the practice workbook orders.xlsx. It has three sheets: Orders, Products and Customers.
  2. In the Orders sheet, the data is in rows 2–13. Column J (value) already contains =G2*H2 (quantity × unit price).
  3. Write your formulas in the empty columns to the right, starting at column K.

Which Excel do I need?

  • IF, SUMIFS, COUNTIFS, INDEX/MATCH and conditional formatting: every Excel version.
  • XLOOKUP, FILTER and LET: Microsoft 365, Excel 2021 or newer, Excel for the web, or the mobile apps. On Excel 2019 or older, use the alternatives given in those lessons: INDEX/MATCH instead of XLOOKUP, and AutoFilter or a PivotTable instead of FILTER.

By the end of this module you can: label and classify data with logic, build KPI summaries with SUMIFS and COUNTIFS, combine sheets with lookups, pull live filtered lists, and make important rows stand out visually.
