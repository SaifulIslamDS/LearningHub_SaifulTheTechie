How to Learn Here

A simple routine for getting from complete beginner to job-ready with this site.

The learning loop

Use this learning loop. Reading alone will not make you job-ready.

  1. Understand the mental model before memorising syntax.
  2. Type and run the examples yourself rather than only copying them.
  3. Follow the build from the starter practice files when a tutorial provides them.
  4. Compare real output with the verified output shown in the lesson.
  5. Extend the implementation or answer the professional-context question.

Some tutorials also include exercises, quizzes or interview checks when those genuinely improve the topic.

Then click Mark lesson as complete. Your progress is saved in this browser only; nothing is sent anywhere.

Finding your way

  • The menu button ☰ (top left, or press M) shows or hides the full curriculum: phases, modules and lessons. It stays open while you move between lessons until you press the button again.
  • Search (press /) finds lessons, glossary terms, tools and planned topics.
  • Glossary: every lesson ends with its Key terms. Click one for a plain-English definition, or browse all terms on the Glossary page.
  • Each lesson has Previous / Next buttons at the bottom and an On this page list on wide screens.

Which path should I follow?

  • New to data? Start at Phase 0, then Phase 1. Don’t skip ahead.
  • Already use Excel or SQL at work? Skim the tutorial outcomes and verified examples. If you can reproduce the result and explain the mental model, move on.
  • Targeting a specific job? Pick a role track on the home page and follow its phases first.

The skip rule

Skip what you already know well. Review what you know weakly. Practise deeply what matters for your target job.

Build evidence as you go

Employers hire on proof, not on certificates alone. Every phase ends with a milestone project. Keep each one in a public GitHub repository with a short README covering:

  • the business question,
  • what you built,
  • the result (numbers, screenshots),
  • what you would improve next.

Use the AI Mentor Prompt

Every written tutorial includes a professional AI Mentor Prompt near the end. Copy it into ChatGPT, Claude, Gemini or another capable assistant when you want an interactive study session. The prompt tells the assistant to diagnose your current understanding, give you a small task, wait for your attempt, review and debug your work, increase difficulty gradually, and verify fast-changing facts against current official documentation.

Treat the prompt as a tutor mode, not an answer generator: keep your editor, terminal, SQL client or notebook open and do the work yourself.

Use AI tools the right way

AI assistants are allowed, and you should use them. Follow two rules:

  • Ask the AI to explain, not just to answer. “Why does this query need HAVING?” teaches you more than “fix my query”.
  • Verify everything. Run the code, check the numbers, and read the official docs. AI tools can be confidently wrong.

Free resources

Every lesson ends with hand-picked free resources: official documentation, interactive exercises and free courses. Selected tutorials also include one reviewed YouTube video companion in an embedded frame, with a note explaining why it is relevant and, where useful, recommended timestamps. Use these to reinforce the written tutorial, not replace it.

Working offline

You can use this whole site without internet: download the repository and open docs/index.html in your browser. Search, the glossary, light/dark mode and progress tracking work offline; quiz scores also work on tutorials that include quizzes (scores and progress are saved in your browser only). Only the external resource links need internet.
