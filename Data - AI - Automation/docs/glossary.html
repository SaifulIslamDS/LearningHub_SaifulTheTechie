Glossary

199 key terms in plain English, from SQL and DAX to RAG and AI agents. Each term links to the lesson where it is taught, and lessons link back here under Key terms.

A

A/B testData & analytics

An experiment that shows two versions (A and B) to random groups and uses statistics to decide whether the difference in results is real or chance.

Also: AB test, A/B testing, experiment

Learn it: A/B Testing Part 1: Hypothesis Tests and Significance

Action titleData & analytics

A chart title that states the conclusion ("March drives the Q1 gap") instead of describing the contents ("Revenue by month").

Learn it: Stakeholder Communication: The Right Message, Chart and Channel · Also used in: Plotly & Analytical Storytelling

AGENTS.mdAgents & automation

A file in a repository with instructions for AI coding agents: setup commands, rules and checks to run before finishing.

Also: project instructions, CLAUDE.md

Learn it: Coding Agents, Copilots & Prompting for Code

AI agentAgents & automation

An AI system that decides its own next steps, using tools (search, code, APIs) in a loop until the goal is reached.

Also: agent, agents, agentic AI

Learn it: Agent Architecture — planned for M10 · v1.1

AI governanceAI operations & governance

Policies, roles and controls that make sure AI systems are legal, safe, fair, documented and accountable.

Also: responsible AI, EU AI Act, ai policy

Learn it: AI Governance & Responsible AI — planned for M12 · v1.3

Apache IcebergData engineering

An open table format with a catalog, snapshots, schema evolution and file-level statistics, readable by many engines (Spark, Trino, Snowflake, DuckDB…).

Also: iceberg, pyiceberg, iceberg table, open table format

Learn it: Apache Iceberg & Lakehouse Platforms: Fabric, Databricks, Snowflake · Also used in: Delta Lake & the Medallion Architecture

APIData engineering

Application programming interface: a defined way for programs to request data or actions from another system, usually over HTTP with JSON.

Also: REST API, endpoint

Learn it: REST APIs, Authentication & Pagination: Pull Data Like a Pro

Average order valueData & analytics

Net revenue divided by the number of net orders. On the practice data, 9,075 ÷ 11 = 825.

Also: AOV

Learn it: DAX Measures & KPI Logic: Revenue, AOV and Target Achievement

B

Bias-variance trade-offMachine learning

Simple models miss patterns (high bias, underfitting); complex ones memorise noise (high variance, overfitting). The best model sits where the validation score peaks.

Also: bias, bias/variance, model complexity, underfitting vs overfitting

Learn it: Feature Engineering & Bias/Variance: Better Inputs, the Right Complexity

BigQueryData engineering

Google Cloud's serverless, columnar data warehouse. On-demand queries are billed by bytes scanned, so selecting fewer columns and partitioning tables saves money.

Also: google bigquery, cloud data warehouse

Learn it: Slowly Changing Dimensions & BigQuery: History and the Cloud Warehouse

BookmarkPower BI & DAX

A saved view of a Power BI report page (filters, visible visuals) that a button can switch to.

Also: bookmarks

Learn it: Power BI Drill-through & Bookmarks: Guided Detail and Saved Views

BootstrapData & analytics

Estimating uncertainty by resampling the data with replacement thousands of times and recomputing the statistic. Works for medians, ratios and model scores.

Also: bootstrapping, resampling

Learn it: Statistics Part 2: Correlation and Confidence Intervals

BranchGit & DevOps

A separate line of work in a repository. Each feature or fix gets a branch, which is merged back into main when ready.

Also: git branch, git switch, feature branch, main branch

Learn it: Branches & Merge: Work on Changes Without Breaking Main

BreakpointPython & tools

A marker that pauses a running program on a chosen line so you can inspect variables and step through the code.

Also: debugger, breakpoint(), pdb

Learn it: Debugging: Read Tracebacks and Use Breakpoints Instead of Guessing

C

CALCULATEPower BI & DAX

The DAX function that changes the filter context before calculating, for example delivered revenue only, or a total ignoring the region filter.

Also: ALL, REMOVEFILTERS

Learn it: DAX CALCULATE & Filter Context: Control What Each Number Includes

Calculated columnPower BI & DAX

A DAX column computed row by row when data refreshes and stored in the model. Prefer measures for totals.

Also: calculated columns

Learn it: DAX Measures & KPI Logic: Revenue, AOV and Target Achievement

CASE expressionSQL & databases

If-then-else logic inside a SQL query, used to create categories such as size bands or status groups.

Also: CASE, case when

Learn it: SQL CASE: Add If-Then Logic to Your Queries

Change data captureData engineering

Capturing row-level inserts, updates and deletes from a source so downstream systems can process changes without repeatedly scanning the whole table.

Also: CDC

Learn it: Replayable Pipelines and Change Data Capture

ChunkingLLMs & RAG

Splitting documents into smaller passages before embedding them, so retrieval returns focused, relevant text.

Also: chunks, chunk size

Learn it: Advanced RAG — planned for M9 · v1.0

CIGit & DevOps

Continuous integration: every push and pull request is automatically installed, linted and tested on a clean machine.

Also: continuous integration, ci/cd

Learn it: GitHub Actions: Run Lint and Tests on Every Push

ClassPython & tools

A blueprint that bundles data and the behaviour that belongs to it. Each object created from it is an instance.

Also: object, instance, oop, object-oriented

Learn it: OOP & Type Hints: Classes, Dataclasses and Clear Contracts

ClassificationMachine learning

Predicting a category, such as whether an order will be cancelled or which defect type an image shows.

Also: classifier, logistic regression

Learn it: Classification — planned for M11 · v1.2 · Also used in: scikit-learn & the Train/Test Split

CLIPython & tools

A program you run by typing a command with options in the terminal, such as csv-clean data/orders_raw.csv -v.

Also: command-line interface, command line tool, argparse

Learn it: Phase 0 milestone project

Coding agentAgents & automation

An AI assistant that reads a code project, edits files, runs commands and tests, and may open pull requests for review.

Also: coding agents, coding assistant, agent mode, github copilot

CommitGit & DevOps

A saved snapshot of chosen changes, with a message, author and unique ID. You stage changes with git add, then commit them.

Also: git commit, staging area, git add

Learn it: Git Repositories & Commits: Save Your Work in Safe Steps

Computer visionMachine learning

AI that understands images and video, for example detecting defects on a production line.

Also: CV, image classification, object detection

Conditional formattingExcel

Rules that change a cell's colour or icon based on its value, such as red for below target.

Learn it: Excel Conditional Formatting: Make Important Data Stand Out · Also used in: Power BI Report Basics

Confidence intervalData & analytics

A range of plausible values for something estimated from a sample, e.g. 'late rate 23.7% (95% CI 22.4–25.1%)'. It narrows as the sample grows.

Also: 95% confidence interval, confidence intervals, margin of error, standard error

Learn it: Statistics Part 2: Correlation and Confidence Intervals · Also used in: Matplotlib & Seaborn

ConfoundingData & analytics

When a third variable drives both the supposed cause and the outcome, creating a misleading relationship. Simpson's paradox is the extreme case where the direction flips within groups.

Also: confounder, confounding variable, simpson's paradox

Learn it: A/B Testing Part 2: Sample Size, Peeking and Causal Pitfalls · Also used in: EDA Part 2

Context engineeringLLMs & RAG

Deciding exactly what information, tools and instructions an AI model sees for each step, so it has what it needs and nothing distracting.

Learn it: Prompt & Context Engineering — planned for M9 · v1.0

Context windowLLMs & RAG

The maximum amount of text (in tokens) an LLM can consider at once, including instructions, documents and the conversation.

Also: context length

Learn it: Prompt & Context Engineering — planned for M9 · v1.0

CorrelationData & analytics

A number from −1 to +1 for how consistently two variables move together. Pearson measures straight-line relationships; Spearman uses ranks and resists outliers. Correlation is not causation.

Also: pearson, spearman, correlation coefficient, r squared

Learn it: Statistics Part 2: Correlation and Confidence Intervals · Also used in: EDA Part 2

cronGit & DevOps

A scheduler that runs commands at set times using five time fields, such as 0 6 * * 1-5 for 06:00 on weekdays.

Also: crontab, schedule

Learn it: grep, sort & Pipes, then cron: Answer Questions and Automate Jobs · Also used in: GitHub Actions

Cross-validationMachine learning

Splitting the training data into k parts and letting each take a turn as the validation set, then averaging. Gives a more reliable score (with a ± range) than one split.

Also: cross validation, k-fold, kfold, stratifiedkfold

Learn it: Feature Engineering & Bias/Variance: Better Inputs, the Right Complexity

CSVPython & tools

A plain-text table: one row per line, values separated by commas. Every value is read as text until you convert it.

Also: comma-separated values, DictReader

Learn it: Files & Exceptions: Read and Write Data Safely · Also used in: Web Scraping and File Formats

CTESQL & databases

A named, temporary result defined with WITH at the start of a query. It makes multi-step SQL readable.

Also: common table expression, WITH clause, recursive cte, with recursive

Learn it: CTEs and Recursive CTEs: Readable Multi-Step SQL · Also used in: SQL Subqueries

An explicit producer-consumer agreement covering the structure, meaning, ownership, versioning and delivery expectations of a dataset.

Also: data contracts

How recent the newest trustworthy data is compared with when consumers expect it to arrive; thresholds can warn or block stale outputs.

Also: freshness check, freshness threshold

Learn it: Data Contracts, Freshness and Alerting
