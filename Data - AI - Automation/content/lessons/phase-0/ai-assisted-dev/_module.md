AI coding assistants now write a large share of everyday code. Employers expect you to **use them well**, with clear instructions and small steps, and to **take responsibility** for what they produce through review and tests. This module covers both sides.

**By the end of this module you can:** choose between inline assistants, chat and coding agents; write prompts and project instruction files (AGENTS.md) that produce good code; and review and test AI-written code before it reaches your main branch.
