**pandas** is the standard Python library for tables. A pandas **DataFrame** is like an Excel sheet or a SQL table that you control with code: load, clean, join, group, pivot and export, with every step repeatable. These lessons use **pandas 3.0** (released in 2026), whose main changes are a dedicated text type (`str`) and copy-on-write behaviour. Most older tutorials still work.

All examples use the scripts and data in [data-science-scripts.zip](../../../downloads/phase-2/data-science-scripts.zip) (see the [NumPy module](../numpy/index.html) for setup).

**By the end of this module you can:** explore a DataFrame, clean a messy export into a validated table, join and summarise tables, and analyse data over time with pivots and date tools.
