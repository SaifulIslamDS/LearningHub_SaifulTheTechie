A **data model** connects several tables, such as orders, customers, products, regions, dates and targets, so one report can slice by all of them. **DAX** is the formula language for that model. These are the same skills in Excel's **Power Pivot** and in **Power BI**, and they are the core of the PL-300 exam.

!!! tip "Which tool should I practise in?"
    - **Power BI Desktop** (free, Windows only) is recommended. Everything in these lessons works there, and it's the tool most job descriptions ask for.
    - **Excel Power Pivot** (Excel for Windows with Microsoft 365 or the Professional editions; not available in Excel for Mac) uses the same DAX. Differences are noted in each lesson.
    - On a Mac, use Power BI through a Windows virtual machine or a cloud PC.

!!! note "Practice file"
    [sales_model.xlsx](../../../downloads/sales_model.xlsx) contains five ready-made Excel Tables: **Orders** (12 rows), **Customers** (6), **Products** (6), **Regions** (4) and **Targets** (12 rows: region × month). These are the clean results of the Power Query lessons.

**By the end of this module you can:** build a star-schema model with a date table, write measures for revenue, orders, average order value and target achievement, and use CALCULATE to control filters, for example to get shares of total or month-on-month growth.
