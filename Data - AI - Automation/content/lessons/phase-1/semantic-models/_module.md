A **semantic model** turns raw tables into a business-facing layer with trusted relationships, dimensions, measures and definitions. The goal is not only to make a dashboard work, but to make the same KPI mean the same thing wherever it is reused.

!!! tip "Learning focus"
    Use this module to connect star-schema thinking, metric definitions and reusable measures. By the end, you should be able to explain why a governed semantic layer reduces duplicated logic and inconsistent reporting.
