**Power BI** turns the data model from the previous module into interactive reports, then shares them securely through the Power BI service. In this module you build a sales report, add drill-through and bookmarks, restrict data per manager with row-level security, then publish and explore Copilot.

!!! tip "What you need"
    - **Power BI Desktop**: free, Windows 10 or later. Install it from the Microsoft Store (automatic updates, no admin rights needed) or download it directly. There is no Mac version.
    - **Power BI service** (app.powerbi.com): needed only for the publishing lesson. Sign-in uses a work or school account, and sharing with others needs a paid licence (details in that lesson).
    - Your model from the DAX lessons, or [sales_model.xlsx](../../../downloads/sales_model.xlsx) to rebuild it.

**By the end of this module you can:** design a clean one-page KPI report, add drill-through detail pages and bookmark views, secure data by region, publish to a workspace, and explain what Copilot needs and how to check its answers.
