SQL is the language used to ask questions of data stored in databases. In this module you work with a small sales table, and later a customers table, and learn to answer real business questions with it: *which orders came from Dhaka? Who are our top customers? How much revenue did each region bring in?*

!!! tip "Set up once, practise every lesson"
    1. Install **DB Browser for SQLite** (free, Windows/macOS/Linux) — or use any SQL tool you already have.
    2. Create a new database, open the **Execute SQL** tab, and run the practice file [orders.sql](../../../downloads/orders.sql).
    3. You now have the `orders` and `customers` tables used in every example. Prefer spreadsheets? The same data is in [orders.csv](../../../downloads/orders.csv) and [customers.csv](../../../downloads/customers.csv), or [orders.xlsx](../../../downloads/orders.xlsx).

**By the end of this module you can:** filter, sort, group and join business data; write the queries behind a KPI report; and explain your query logic in an interview.
